# Generated AR Lesson Models

This folder contains portable `.obj` versions of the models used by the AR lessons:

- `TrianglePrism.obj`
- `CubeSixFaces.obj`
- `PhysicsBall.obj`
- `PhysicsTrack.obj`

For Unity-native mesh/material assets, open the project in Unity and run:

`AR Education -> Generate AR Model Assets`

The scene and prefab builders also call this generator automatically before creating AR lesson scenes or prefabs.
