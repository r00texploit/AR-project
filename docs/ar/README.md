## ملخص سريع

- إصدار Unity المستخدم في المشروع: `6000.4.8f1`.
- حزمة التطبيق: `com.areducation.app`.
- أقل إصدار Android: API 24، أي Android 7.0.
- هدف Android الحالي: API 34.
- معمارية البناء: ARM64.
- حزم الواقع المعزز: AR Foundation و ARCore و ARKit بإصدار `6.4.3`.

## أسرع مسار للتشغيل

1. افتح المشروع في Unity Hub باستخدام Unity `6000.4.8f1` أو إصدار متوافق من Unity 6.
2. انتظر حتى ينتهي Unity من استيراد الحزم وتجميع السكربتات.
3. من شريط القوائم داخل Unity شغّل:

```text
AR Education > Setup All Scenes
```

4. افتح مشهد `Assets/Scenes/MainMenu.unity`.
5. اضغط زر التشغيل داخل Unity لاختبار القائمة والاختبارات ولوحة المعلم.
6. لتجربة الواقع المعزز فعليًا، ابنِ التطبيق على جهاز Android يدعم ARCore.

للتفاصيل الكاملة راجع [02-تشغيل-التطبيق.md](02-تشغيل-التطبيق.md) و [03-بناء-ملف-apk.md](03-بناء-ملف-apk.md).
