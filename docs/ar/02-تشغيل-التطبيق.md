# تشغيل التطبيق

## المتطلبات

| الأداة | الإصدار أو الملاحظة |
|---|---|
| Unity Hub | أحدث إصدار متاح |
| Unity Editor | `6000.4.8f1`، أو إصدار متوافق من Unity 6 |
| Android Build Support | مطلوب لبناء APK |
| Android SDK & NDK Tools | يفضل تثبيتها من Unity Hub مع Android Build Support |
| OpenJDK | يثبت عادة مع وحدة Android في Unity |
| Git | مطلوب إذا كنت ستنسخ المشروع من مستودع Git |
| جهاز Android | Android 7.0 أو أحدث، ويدعم ARCore |

## فتح المشروع في Unity

1. افتح Unity Hub.
2. اختر `Projects`.
3. اضغط `Add` ثم `Add project from disk`.
4. اختر مجلد المشروع:

```text
/Users/halim/AR-project-main
```

5. افتح المشروع باستخدام Unity `6000.4.8f1` أو إصدار Unity 6 متوافق.
6. انتظر حتى ينتهي Unity من استيراد الحزم وتجميع السكربتات.

قد يستغرق الفتح الأول عدة دقائق لأن Unity سيحمّل الحزم الموجودة في:

```text
Packages/manifest.json
```

## تجهيز المشاهد

يحتوي المشروع على سكربت Editor يقوم ببناء المشاهد وربط المكونات تلقائيًا. شغّله من شريط القوائم داخل Unity:

```text
AR Education > Setup All Scenes
```

هذا الأمر يقوم بتجهيز المشاهد التالية وحفظها:

```text
Assets/Scenes/MainMenu.unity
Assets/Scenes/ARLesson.unity
Assets/Scenes/Quiz.unity
Assets/Scenes/TeacherDashboard.unity
```

كما يقوم `BuildPreprocessor` بتشغيل تجهيز المشاهد تلقائيًا قبل أي عملية بناء.

## تشغيل المشاهد داخل Unity Editor

يمكن اختبار بعض أجزاء التطبيق مباشرة داخل Unity:

| المشهد | يعمل داخل Editor؟ | الملاحظات |
|---|---|---|
| `MainMenu.unity` | نعم | اختبار التنقل والإعدادات |
| `Quiz.unity` | نعم | اختبار الأسئلة وحساب الدرجات |
| `TeacherDashboard.unity` | نعم | عرض النتائج المخزنة |
| `ARLesson.unity` | جزئيًا | تحتاج تجربة AR الفعلية إلى جهاز يدعم ARCore |

لتشغيل مشهد:

1. افتح المشهد من `Assets/Scenes`.
2. اضغط زر التشغيل `Play`.
3. ابدأ عادة من `MainMenu.unity` لأن هذا المشهد ينشئ بعض الكائنات المستمرة مثل `DataManager` و`SceneLoader`.

## تشغيل التطبيق على جهاز Android

1. تأكد أن الجهاز يدعم ARCore.
2. ثبّت `Google Play Services for AR` من متجر Google Play إذا لم يكن مثبتًا.
3. فعّل `Developer Options` على الهاتف.
4. فعّل `USB Debugging`.
5. صل الهاتف بالكمبيوتر عبر USB.
6. في Unity افتح:

```text
File > Build Settings
```

7. اختر `Android`.
8. اضغط `Switch Platform` إذا لم يكن Android هو المنصة الحالية.
9. اضغط `Build And Run`.

سيقوم Unity ببناء التطبيق وتثبيته مباشرة على الجهاز المتصل.

## إعداد XR Plug-in Management

افتح:

```text
Edit > Project Settings > XR Plug-in Management
```

ثم:

- في تبويب Android فعّل `ARCore`.
- في تبويب iOS، إذا كنت تحتاج iOS، فعّل `ARKit`.

## استيراد موارد TextMeshPro

إذا ظهرت النصوص بشكل غير صحيح أو ظهرت عناصر وردية، شغّل:

```text
Window > TextMeshPro > Import TMP Essential Resources
```

ثم اضغط `Import`.

## مشاكل شائعة

### لا تظهر قائمة AR Education

السبب غالبًا وجود أخطاء Compile تمنع تحميل سكربتات Editor.

الحل:

1. افتح `Window > General > Console`.
2. أصلح الأخطاء الحمراء.
3. انتظر إعادة التجميع.
4. جرّب تشغيل `AR Education > Setup All Scenes` مرة أخرى.

### درس AR لا يعمل داخل Editor

هذا طبيعي. كاميرا الواقع المعزز واكتشاف الأسطح تحتاج جهازًا فعليًا يدعم ARCore أو ARKit.

### رسالة أن الجهاز لا يدعم AR

تأكد من:

- الجهاز موجود ضمن أجهزة ARCore المدعومة.
- خدمة `Google Play Services for AR` مثبتة ومحدثة.
- التطبيق حصل على صلاحية الكاميرا.

### بيانات الاختبار لا تظهر

تأكد من وجود ملفات JSON في:

```text
Assets/Resources/QuizData/
```

الأسماء المتوقعة:

```text
triangle_quiz.json
physics_quiz.json
cube_quiz.json
```
